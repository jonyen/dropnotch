# App Icon — Design

**Date:** 2026-07-27
**Status:** Approved

## Problem

DropNotch ships without an app icon. Because the app is `LSUIElement`, the icon
never appears in the Dock — but it does appear everywhere the user actually
meets the app as an object:

- Finder, on `DropNotch.app`
- System Settings → General → Login Items
- System Settings → Privacy & Security → Screen Recording and Accessibility
- The "Grant Permissions…" alert raised from the status menu

Today all of those show a blank generic-application icon, which reads as
untrustworthy in exactly the panes where the user is deciding whether to grant
the app screen and accessibility access.

## Concept

The icon *is* the notch. Not a metaphor for it — the hardware silhouette.

- A dark graphite squircle stands in for the MacBook display.
- A pure-black notch hangs from the top edge: square where it meets the bezel,
  rounded bottom corners. This is the same shape language as the dropdown panel
  (`NotchPanelController.applyPanelShape`), so icon and UI agree.
- Three white menu-bar-style dots drop out beneath the notch — the hidden items
  DropNotch reveals.

## Architecture

Artwork is generated by code, not stored as a binary blob: a ~100-line drawing
routine is diffable, reviewable, and re-renderable at any size, and needs no
design tooling.

Three pieces, each with one job:

| Unit | Responsibility | Depends on |
|---|---|---|
| `IconArt` (library target) | Pure geometry + Core Graphics drawing | AppKit only |
| `IconGen` (executable target) | Emit `AppIcon.iconset`, invoke `iconutil` | `IconArt` |
| `scripts/make-app.sh` | Copy `.icns` into the bundle | the generated file |

`IconArt` is a separate target from `DropNotchCore` on purpose: icon-drawing
code has no business in the shipping app binary, and the split keeps the
geometry unit-testable without the app depending on it.

### Geometry

All measurements are proportional to the canvas so every size renders from one
routine. Within a 1024pt canvas the squircle is inset to the macOS icon grid
(~824pt), and relative to that squircle side `S`:

- notch: width `0.46·S`, height `0.17·S`, bottom corner radius `0.055·S`
- dots: radius `0.045·S`, spaced `0.14·S`, centred below the notch
- squircle corner radius: `0.225·S`, continuous curve

### Small sizes

At 16px the three dots merge into a smudge. `IconArt.dotCount(forPixelSize:)`
returns 1 at or below 32px and 3 above, so the small variants stay legible.

## Data flow

```
swift run IconGen
  └─ IconArt.draw(size:) ──> PNG × 10  (16,32,128,256,512 @1x/@2x)
       └─ build/AppIcon.iconset/
            └─ iconutil -c icns ──> Resources/DropNotch.icns   [committed]

scripts/make-app.sh
  └─ cp Resources/DropNotch.icns  →  DropNotch.app/Contents/Resources/
       └─ Info.plist: CFBundleIconFile = DropNotch
```

`Resources/DropNotch.icns` is committed. It is a build *input* to
`make-app.sh`, not an output, and `.gitignore` covers only `build/` and
`.build/`. Regenerating it is an explicit `swift run IconGen`, so a normal
`make-app.sh` run does not require the generator to work.

## Error handling

- `IconGen` fails loudly (non-zero exit) if a PNG fails to encode or `iconutil`
  returns non-zero. A half-written iconset must never be packaged.
- `make-app.sh` treats a missing `.icns` as fatal rather than silently building
  an icon-less bundle, since that failure is otherwise invisible until someone
  opens System Settings.

## Testing

Unit tests against `IconArt`'s pure helpers — no golden-image comparison, which
would be brittle across OS releases:

- notch rect is horizontally centred within the canvas (symmetry)
- notch and dot metrics scale proportionally: geometry at 512 is exactly half
  the geometry at 1024
- `dotCount(forPixelSize:)` returns 1 at 16 and 32, 3 at 64 and above
- dot centres are symmetric about the canvas midline
- every rendered size is non-blank (some non-background pixel) and has the
  expected pixel dimensions

## Out of scope

- Changing the status bar glyph (`rectangle.topthird.inset.filled`) — the menu
  bar wants a template SF Symbol, not this artwork.
- A macOS 26 layered/"glass" icon variant. A single flat `.icns` is what the
  hand-rolled bundle script can consume today.
